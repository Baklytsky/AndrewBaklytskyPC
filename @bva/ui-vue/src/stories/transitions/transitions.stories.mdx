# Transitions

Transitions help users understand the flow of their actions.

## Basic Transitions

Bedrock provides a few transitions to cover basic functionalities such as fading, scaling, and sliding-in:
  - `ra-fade`
  - `ra-slide-left`
  - `ra-slide-right`
  - `ra-slide-top`
  - `ra-slide-bottom`

To use them, simply set the desired transition as the `name` property of Vue's `<transition>` wrapper:

```html
<transition name="ra-fade">
  <p v-if="show">Hello</p>
</transition>
```

## Customization

Transitions can be customized by following Vue's standard functionality.
To do so, modify the CSS properties for one more of its states:
  - `enter-from`
  - `enter-active`
  - `enter-to`
  - `leave-from`
  - `leave-active`
  - `leave-to`

Which means that to change the look and feel of the `ra-slide-left` transition,
you would then update one or more of these classes and their properties:
  - `.ra-slide-left-enter-from`
  - `.ra-slide-left-enter-active`
  - `.ra-slide-left-enter-to`
  - `.ra-slide-left-leave-from`
  - `.ra-slide-left-leave-active`
  - `.ra-slide-left-leave-to`

To learn more about Vue transitions, head to the [Vue.js Transition Docs](https://vuejs.org/guide/built-ins/transition.html).
